# Packs

This public staging includes only Pack material selected as publication-safe.

The private development tree contains additional domain Pack fixtures and historical candidates that are intentionally excluded until per-Pack provenance/privacy review is complete.

Rules:
- Packless Core is supported.
- Promotion != Install.
- Install != Activate.
- Deactivate != Uninstall.
- Update does not rewrite history or auto-adopt.
- Running Jobs pin exact Pack revisions.
- Generic Pack Factory is not a product goal.

Representative Pack Formation remains a Program proof gap.
