# Governance

Public governance principles:

- one active authority owner per stable fact class;
- candidate source is not Stable Authority;
- current run/SHA/stage lives in Build Status/Handoff, not Stable Sources;
- accepted baselines are inherited unless a changed consumer invalidates them;
- model proposes; Runtime governs persistence/permission/Promotion;
- no automatic Pack Promotion/install/activation;
- Project, Pack, Provider, Shell, MCP and Local Action identities remain distinct;
- local canonical effects require explicit bounded approval;
- public Git history is source-control evidence, not Production-state authority.

The private build may contain additional receipts and internal governance material that is not part of this sanitized repository.
