# Contributing

1. Read `AGENTS.md` and `docs/PROJECT_EXPERIENCE_CONTRACT.md`.
2. Check the pinned LibreChat upstream state and `CUSTOM_SEAMS.yaml`.
3. Prefer deletion/reuse over parallel custom implementation.
4. Make one bounded change.
5. Run the public-source guard and affected tests.
6. Explain which proof family changed and which accepted baseline remains inherited.
7. Do not publish or deploy from a pull request.

For LibreChat-facing changes, state the upstream capability checked, the genuine remaining gap, and the retirement trigger for the custom seam.
