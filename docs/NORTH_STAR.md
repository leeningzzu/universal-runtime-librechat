# North star

Any supported Windows PC should provide one shared LibreChat-based AI Web/Desktop experience backed by Runtime Authority/Governance and optional governed Packs.

The Core Product must remain useful with zero user Packs.

The shell should feel simple:
- Project-first
- New Chat
- direct request
- automatic continuity where appropriate
- no normal-user PowerShell, ports, Docker, MCP, executor or SHA handling

The implementation may exceed LibreChat's current native behavior where the product experience requires it, but custom extensions must remain narrow, replaceable and easy to delete when upstream catches up.
