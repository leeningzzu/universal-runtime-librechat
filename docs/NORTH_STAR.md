# Aides — North star

Aides is a local-first, Project-first AI workbench using **the existing LibreChat shell** with Runtime Authority/Governance. Universal Runtime remains the internal control-plane role, not a second user shell.

The user-confirmed product sequence is:

1. Complete the ChatGPT-Projects-like **Project** experience first: New Project -> New Chat -> direct request; Instructions, Memory, Files/Sources, same-Project history/recall, source-grounded work, durable Artifacts, clear Archive/Delete and data safety.
2. Combine mature **LibreChat native** model/provider choice, Agents, Skills, MCP, tools and connectors in that one Project experience; do not rebuild any of these generic platforms.
3. Make the governed **optional Pack** capability user-valuable: Project-derived Overlay/Skill -> Domain/Universal Pack Candidate as supported by independent evidence -> explicit Promotion -> optional Install/Activate/Deactivate/Uninstall/Update. Zero user Packs must always support normal Projects.
4. Finally package the accepted experience as one installable **Windows EXE** for a fresh installation and first Project on **any supported Windows PC**. A fresh installation does **not** require an external cloud service, old-computer Project export, cloud sync or cross-computer history transfer.

Protect accepted baseline and affected user data across restart/update/repair/rollback; treat migration of old Project data to another PC as a distinct optional feature, not a condition for EXE installation.

Normal users should not need to operate PowerShell, Docker, ports, MCP configuration, execution IDs, SHA values or proxy settings. Networking is optional for chosen hosted model Providers or external tools, not required for the local Project store itself.

No second Shell, Chat DB, File DB, Search DB, Library platform, Agent harness, Skill engine, MCP platform, or generic Pack factory without a proven independent remaining gap.
