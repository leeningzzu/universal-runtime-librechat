# Current public baseline

This file describes the public-source proof ceiling only. It is not a Production-status authority.

Accepted design direction:
- LibreChat is the single replaceable shell.
- Runtime owns governance/currentness/permission/audit, not the final UI.
- Project Core is usable without optional user Packs.
- Project continuity, Memory and exact Source semantics may extend LibreChat where native behavior is insufficient.
- Pack consumer lifecycle has been proven in the private build, but Pack Formation representative flow remains open.
- Portable ArtifactStore and privacy clean-room have been proven in the private build.
- Fresh install/repair/update/uninstall and final packaging remain open.
- ChatAnywhere native per-user model catalogue recovery has an exact source patch, isolated two-user/cache proof, and current-machine menu visibility proof; one natural Human selection remains open, and individual model callability is not claimed.
- R085 publishes a sanitized LibreChat v0.8.8 source patch that keeps the whole cumulative Project-first Client while adding direct-forward complete Project deletion and the full Project-scoped Installed Pack lifecycle. Isolated proof covers 72 capability families, 29 authenticated browser checks, one synthetic browser delete in 6.437 seconds with zero global backup, and two independent 19/19 reliability runs. This public record is not Production authority; Production adoption, real-user acceptance, Product PASS and Program PASS remain open.
- Product PASS and Program PASS are not claimed.

The private build contains additional receipts and user data that are intentionally excluded from this public staging.
