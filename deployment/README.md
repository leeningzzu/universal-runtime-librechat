# Deployment

The current public staging intentionally does not contain Production secrets, Mongo data, browser state, Docker volumes or installer binaries.

The Windows Product target is an ordinary supported Windows PC with one shared LibreChat shell, automatic Runtime/local-service lifecycle, no normal-user PowerShell/port/Docker/MCP/executor handling, and accepted fresh install, repair, update, rollback and uninstall.

Final installer/updater ownership remains open pending mature-tool selection and acceptance.
